# <i class="fa-solid fa-book-open"></i> Recent Papers

One recent favorite per faculty member (alphabetical by first
name). For the full story, see each lab's own site — and for the
big picture, see [AI @ SE @ NC State](ai.html).

- **Bowen Xu**: [Understanding Codebase like a Professional!
  Human-AI Collaboration for Code
  Comprehension](https://arxiv.org/abs/2504.04553), ICPC 2026 —
  **ACM SIGSOFT Distinguished Paper Award**.
- **John-Paul Ore**: [Analyzing the dependability of Large
  Language Models for code clone
  generation](https://doi.org/10.1016/j.jss.2025.112548), Journal
  of Systems and Software, 2025.
- **Katie Stolee**: [How Do Developers Interact with AI? An
  Exploratory Study on Modeling Developer Programming
  Behavior](https://doi.org/10.1145/3808120), FSE 2026 — a
  76-developer study of how intentions, actions, and emotions
  shift when programming with AI.
- **Marcelo D'Amorim**: [Testing Deep Learning Libraries via
  Neurosymbolic Constraint
  Learning](https://damorim.github.io/publications/Naziri_ETAL_ICSE26_1.pdf),
  ICSE 2026.
- **Sandeep Kuttal**: [Where Will They Click Next? A Social
  Foraging Model for Collaborating
  Teams](https://doi.org/10.1145/3772318.3791506), CHI 2026 —
  **Honorable Mention** (top of 7,500+ submissions).
- **Sarah Heckman**: [From Covid to GenAI: Tracing Long-term
  Changes of Students' Help-seeking Behaviors in a CS2
  Course](https://sigcsevirtual2026.acm.org/details/sigcse-virtual-2026-papers/19/From-Covid-to-GenAI-Tracing-Long-term-Changes-of-Students-Help-seeking-Behaviors-in),
  SIGCSE Virtual 2026 — six years of data on how the pandemic,
  then GenAI, rewired where students go for help.
- **Tim Menzies**: [How Low Can You Go? The Data-Light SE
  Challenge](https://dl.acm.org/doi/10.1145/3808192) — across
  100+ SE optimization tasks, a few dozen labels and some very
  simple learners match tools that are far slower and far more
  complex.
- **Wesley Assunção**: [Human-Centric Agentic AI for End-to-End
  Dependency
  Upgrades](https://doi.org/10.1109/ICSME67971.2026.00122), ICSME
  2026 — autonomous LLM agents take on maintenance's most dreaded
  chore, with a human in the loop.
